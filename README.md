# 🔎 Document Authenticity Verification Agent

An AI-assisted document verification system built using Google Colab, Python, OCR, Gradio, and Groq.

## 📌 Project Overview

This project analyzes uploaded documents and identifies possible signs of inconsistency or suspicious information.

The system supports:

- PDF documents
- Word documents (.docx)
- TXT files
- JPG/JPEG images
- PNG images
- WEBP images

## ⚙️ Technologies Used

- Python
- Google Colab
- Groq
- OCR
- Tesseract
- PyPDF
- python-docx
- Gradio
- Pillow

## 🔄 Working Process

Upload Document  
↓  
Extract Text  
↓  
OCR for Scanned Documents  
↓  
Analyze Document Information  
↓  
Check for Inconsistencies  
↓  
AI-Assisted Verification Result

## ✨ Features

- Upload documents through a simple interface
- Extract text from digital and scanned documents
- OCR support for image-based PDFs
- AI-assisted document analysis
- Detect possible inconsistencies
- Provide evidence and confidence level
- Supports multiple document formats

## ⚠️ Limitation

The system provides AI-assisted analysis. It does not prove official authenticity unless the document is verified through an authoritative external source.
